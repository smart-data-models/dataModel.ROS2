# dataModel.ROS2

### List of data models

The following entity types are available:
- [geometry_msgs_pose](https://github.com/smart-data-models/dataModel.ROS2/blob/master/geometry_msgs_pose/README.md). A representation of pose in free space, composed of position and orientation

- [nav_msgs_odometry](https://github.com/smart-data-models/dataModel.ROS2/blob/master/nav_msgs_odometry/README.md). Represents an estimate of a position and velocity in free space

- [sensor_msgs_batteryState](https://github.com/smart-data-models/dataModel.ROS2/blob/master/sensor_msgs_batteryState/README.md). Represents the state of a battery, including voltage, current, charge, capacity, and health status
